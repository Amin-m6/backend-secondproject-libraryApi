
Library Management API

A simple RESTful API for managing a library's books, built with FastAPI. This project is intended as a beginner-friendly backend exercise for learning HTTP methods, API routing, request validation, and basic CRUD operations.


Storage note: The current version stores books in an in-memory Python dictionary. Data is lost whenever the application stops or restarts. A database such as SQLite or PostgreSQL can be added in a future version.


Features

Retrieve all books
Retrieve a book by its ID
Add a new book
Partially update a book
Delete a book
Validate request bodies with Pydantic
Return HTTP errors when a book does not exist
Explore and test endpoints using FastAPI's interactive documentation

Installation

Clone the repository:

git clone <YOUR_REPOSITORY_URL>
cd <YOUR_REPOSITORY_FOLDER>
(Recommended) Create and activate a virtual environment:

Windows

python -m venv .venv
.venv\\Scripts\\activate
macOS / Linux

python3 -m venv .venv
source .venv/bin/activate
Install the dependencies:

pip install "fastapi[standard]"

Run the API

From the directory containing main.py, run:


fastapi dev main.py

The development server will usually be available at:


API base URL: http://127.0.0.1:8000
Interactive API docs: http://127.0.0.1:8000/docs
Alternative documentation: http://127.0.0.1:8000/redoc

You can use the interactive documentation to try each endpoint.


Data Model

Each book contains the following fields:



Field Type Description



id Integer Unique identifier generated by the API


title String Book title


author String Author's name


published_year Integer Year the book was published


available Boolean Whether the book is available; defaults to true

Example book response:


{
  "id": 1,
  "title": "Atomic Habits",
  "author": "James Clear",
  "published_year": 2018,
  "available": true
}

API Endpoints

Method Endpoint Description



GET /books Get all books GET /books/{book_id} Get a book by ID POST /books Create a book PATCH /books/{book_id} Update selected fields of a book DELETE /books/{book_id} Delete a book


1. Get all books

GET /books

Returns a list of books. If no books have been added, the response is an empty array:


[]

2. Get a book by ID

GET /books/1

Returns the requested book. If the ID does not exist, the API returns 404 Not Found.


3. Create a book

POST /books
Content-Type: application/json

Request body:


{
  "title": "Atomic Habits",
  "author": "James Clear",
  "published_year": 2018,
  "available": true
}

The API generates the book ID and returns the created book with status 201 Created. The available field can be omitted; its default value is true.


4. Partially update a book

PATCH /books/1
Content-Type: application/json

Request body example:


{
  "available": false
}

Only the supplied fields are updated; the other fields remain unchanged. If the book ID does not exist, the API returns 404 Not Found.


5. Delete a book

DELETE /books/1

Deletes the book with the specified ID. A successful deletion returns 204 No Content. If the ID does not exist, the API returns 404 Not Found.


Error Handling

The API uses standard HTTP status codes, including:


Status code Meaning



201 Created A book was created successfully 204 No Content A book was deleted successfully 404 Not Found No book exists with the requested ID 422 Unprocessable Entity The request data failed validation


Current Limitations

Data is stored in memory and is not persistent.
The API does not yet include authentication or authorization.
The ID-generation approach is suitable for this small learning project, but is not designed for multi-worker production deployments.
Search by title, author, or category has not been implemented yet.

Possible Improvements

Add a database using SQLite or PostgreSQL.
Add search, filtering, sorting, and pagination.
Add automated tests with pytest and FastAPI's test client.
Add authentication and authorization.
Organize the project into separate modules for routes, schemas, and data access.
